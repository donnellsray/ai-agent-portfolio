# AI Agent Portfolio

A collection of AI agents I've designed and built, spanning different platforms and constraints. Each project folder is a short case study — the problem it solves, the workflow and UX thinking behind it, and (where applicable) the underlying prompt or system design.

## Projects

- **[Client Services Weekly Update Writer](./glean-client-services-update-writer)** — A Glean agent that interviews an Account Manager about their week, drafts a leadership-ready update entry, and routes it into the correct team's tracking sheet — replacing a manual, inconsistent weekly reporting process.
